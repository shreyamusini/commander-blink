# commander-blink

Commander Blink is a Brain Computer Interface designed to control pause/play actions of videos with the blink of an eye. Using EEG data, a user can double blink in order to pause or play a Youtube video, where each blink translates to a keyboard shortcut for each action. This interface was tested using real trial data and completed successful live runs.This repository contains all the code (GUI, software, and classifier) for Commander Blink, our final project for COGS 189.
